# Customer Insights – AdventureWorks Customer Profile Analysis

## 📌 Project Overview

Customer Insights is an Excel-based customer profile analysis project using the AdventureWorks dataset.

The objective of this project is to analyze customer information, understand customer characteristics, identify patterns, and generate useful business insights using Microsoft Excel.

## 🎯 Business Objective

The project focuses on:

- Understanding customer profiles
- Analyzing customer demographics
- Identifying customer patterns
- Comparing customer segments
- Finding useful business insights
- Presenting the analysis in an easy-to-understand format

## 🛠️ Tools Used

- Microsoft Excel
- Excel Data Cleaning
- Excel Pivot Tables
- Excel Charts
- Excel Dashboard
- CSV Dataset

## 📊 Project Workflow

1. Collected the AdventureWorks customer dataset
2. Imported the data into Excel
3. Cleaned and prepared the data
4. Analyzed customer information
5. Created Pivot Tables
6. Created charts and visualizations
7. Identified important customer insights
8. Prepared the final presentation

## 📁 Project Files

| File | Description |
|---|---|
| `Customer_Insights.xlsx` | Main Excel analysis and dashboard |
| `Customer_Insights.pptx` | Project presentation |
| `Customer_Data.csv` | Source customer dataset |

## 📈 Key Analysis

The project analyzes customer information to understand:

- Customer demographics
- Customer distribution
- Customer characteristics
- Customer segments
- Business-relevant customer patterns

## 💡 Key Insights

The analysis helps understand customer behavior and characteristics from the AdventureWorks dataset and provides a foundation for making data-driven business decisions.

## 📌 Conclusion

This project demonstrates an end-to-end Excel-based data analysis workflow, including data preparation, analysis, visualization and presentation of business insights.
